REAL CROP PHOTOS (optional)
---------------------------
Drop a photo here named after the crop, lowercase, with dashes for spaces:

    tomato.jpg      onion.jpg      wheat.jpg      green-chilli.jpg

Any lot / crop card for that crop then shows the photo automatically (no code
change). Crops without a file keep the designed cover.

Tips: landscape photo, ~800x450px, JPG/WebP-as-.jpg, under ~150 KB.

A photo attached to an individual lot / farm / crop record (field `imageUrl`)
always wins over the file in this folder.
